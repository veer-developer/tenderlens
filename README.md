# 🔍 TenderLens AI
### Explainable AI Platform for Government Tender Evaluation
**AI for Bharat Hackathon | Theme 3 | PAN IIT Bangalore**

## What It Does
TenderLens automates government tender evaluation using AI:
- Extracts eligibility criteria from tender PDFs automatically
- Evaluates each bidder against every criterion with evidence citations
- Never silently disqualifies — ambiguous cases go to human review
- Full audit trail downloadable as a report

## Tech Stack
Python · Streamlit · Groq (LLaMA 3.3 70B) · PyMuPDF · Tesseract OCR

## How To Run
pip install streamlit groq pymupdf
Add your Groq API key to app.py line 10
streamlit run app.py
